# Hypothesis Testing

## Null and alternative hypothesis

The null hypothesis (H0) states that there is no effect or no difference. The alternative hypothesis (H1) states that an effect exists. A test never proves H0; it only shows whether the data give enough evidence to reject it.

## The p-value

The p-value is the probability of observing data at least as extreme as the sample, assuming that H0 is true. It is not the probability that H0 is true. If the p-value is below the significance level alpha, usually 0.05, H0 is rejected.

## Errors

A type I error means rejecting a true H0, and its probability is alpha. A type II error means failing to reject a false H0, and its probability is beta. The power of a test is 1 minus beta. A larger sample size increases the power.

## Common tests

The t-test compares means: one-sample, two-sample, or paired. The chi-square test checks the relationship between two categorical variables. ANOVA compares the means of three or more groups.

## Confidence intervals

A 95 percent confidence interval is built so that, if the experiment were repeated many times, about 95 percent of such intervals would contain the true parameter. A wider interval means more uncertainty.
